==============================================================
              MiGamepad 部署指南
   小米蓝牙手柄 (MDZ-11-AA) → Xbox 360 虚拟手柄驱动
==============================================================

本包内容:
  MiGamepad.App.exe        主程序 (单文件, 内含 .NET 运行时
                           与 ViGEmBus/HidHide 官方驱动安装器)
  Uninstall-Drivers.ps1    底层驱动卸载脚本 (仅彻底清理时使用)
  Deploy-Guide.txt         本说明

--------------------------------------------------------------
新电脑部署 (全程免联网)
--------------------------------------------------------------

1. 解压到任意目录

2. 以管理员身份运行 (二选一):
      · 双击 MiGamepad.App.exe
      · 或管理员 PowerShell 执行:
        .\MiGamepad.App.exe --install

   程序自动依次完成:
     ① 检测 ViGEmBus / HidHide 驱动, 缺失则用内嵌安装器静默安装
     ② 部署自身到 C:\Program Files\MiGamepad\
     ③ 注册 Windows 服务 (开机自启、崩溃自动重启)
     ④ 启动服务并开始监听手柄
     ⑤ 注册卸载入口 (设置 → 应用 → 安装的应用)

3. 手柄配对:
   按住手柄 MI 键开机; 未配对时长按 MI 键至指示灯快闪,
   Win11 设置 → 蓝牙和其他设备 → 添加设备 → 连接
   "Xiaomi Bluetooth Wireless Gamepad"。

完成。之后开机自动运行, 手柄开机即连, 游戏直接识别为
Xbox 360 手柄 (Player 1 ~ 4 自动分配)。

--------------------------------------------------------------
验证
--------------------------------------------------------------
  · services.msc 查看 "MiGamepad 虚拟手柄服务" 为"正在运行"
  · 日志: %ProgramData%\MiGamepad\service.log
  · 打开 https://gamepad-tester.com 按动手柄验证按键与摇杆
  · 控制面板 joy.cpl 应只有一个 "Controller (XBOX 360 For Windows)"

--------------------------------------------------------------
日常管理
--------------------------------------------------------------
  停止服务     sc stop MiGamepad
  启动服务     sc start MiGamepad
  升级版本     用新版 exe 重新执行 --install (就地覆盖, 无需卸载)
  仅装驱动     .\MiGamepad.App.exe --install-drivers
  手动测试     sc stop MiGamepad 后双击 exe 进入控制台, 按 V 测震动

--------------------------------------------------------------
卸载
--------------------------------------------------------------
  方式一 (推荐): 设置 → 应用 → 安装的应用 → MiGamepad 虚拟手柄服务 → 卸载
  方式二: 管理员 PowerShell 执行  .\MiGamepad.App.exe --uninstall
  可选清理: 删除 C:\Program Files\MiGamepad\
  驱动清理: 管理员运行 .\Uninstall-Drivers.ps1 (会卸载 ViGEmBus/HidHide,
            其他依赖这两个驱动的手柄工具也会受影响, 一般无需执行)

--------------------------------------------------------------
常见问题
--------------------------------------------------------------
  · 服务启动报 1068: 说明 HidHide/ViGEmBus 未运行。重新执行
    --install 会自动修复; 若仍失败, 重启电脑后再次执行。
  · 游戏里能看到两个手柄: 物理手柄未被屏蔽。重连手柄或重启电脑
    让 HidHide 过滤驱动重新挂载。
  · X/Y 需要用大力按: 手柄碳膜触点老化, 属硬件问题, 可清洁触点。
  · 按 MI 键弹出“无法打开此 ms-gamebar 链接”(常见于 Windows 11
    LTSC / 精简版): 这些系统没有 Xbox Game Bar。本程序会自动检测
    并关闭 MI 键的 Guide 映射, 无需处理; 如需强制开关, 执行:
        .\MiGamepad.App.exe --set-guide off   (不映射, LTSC 推荐)
        .\MiGamepad.App.exe --set-guide on    (始终映射)
        .\MiGamepad.App.exe --set-guide auto  (默认, 自动检测)
    修改后重启服务: sc stop MiGamepad && sc start MiGamepad
  · 手柄指示灯呼吸闪烁 = 未连接/正在配对, 不是驱动问题。请在
    Win11 设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙, 选择
    "Xiaomi Bluetooth Wireless Gamepad"; 若手柄仍连在旧电脑上,
    请先关闭旧电脑的蓝牙。
  · 日志反复出现"手柄已连接"但灯还在闪: 蓝牙链路在抖动/断连
    重连。新版已加入去抖(2秒)、重连冷却(5秒)与链路探活, 不会
    再误报; 若仍频繁抖动, 请尝试:
      1) 设置 → 蓝牙和其他设备 → 删除该手柄, 重新配对
      2) 设备管理器 → 蓝牙适配器 → 属性 → 电源管理,
         取消勾选"允许计算机关闭此设备以节约电源"
      3) 让手柄远离 USB3.0 设备/金属遮挡, 缩短距离
